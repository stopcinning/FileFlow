# FileFlow 0.1.0

First release. Windows, single executable, no installer.

## What it does

Point it at a folder and it tells you what is in there. Then it does the
boring parts.

- **Sort by type** — moves everything into folders named after its category
- **Find duplicates** — compares file contents, not filenames, so it finds the
  three copies of the same PDF that all have different names
- **Bulk rename** — by pattern or find-and-replace, previewed before it runs
- **Rules** — conditions and actions, so it can do the same thing every time
- **Cleanup suggestions** — temporary files, build directories, and whatever has
  not been touched in months
- **Undo** — everything, per batch, for as long as you keep the history

## The important part

**Nothing is deleted.** When you remove a file it goes to a quarantine folder
inside the folder you opened. If you do not like what happened, `Ctrl+Z` puts it
back.

Every change is written to a journal before it happens, not after. That ordering
matters: it means a crash mid-operation leaves a record of something that did not
happen, rather than a moved file with no way back.

Undone changes are per batch, and you can pick which batch from the Activity tab
rather than only reversing the most recent thing.

## Duplicate detection, specifically

It groups files by exact byte size first, then hashes only the files that share
a size. On a normal folder that means it reads a small fraction of your disk
rather than all of it, and it finishes quickly on folders where everything is
already unique.

Files over 8 GB are skipped rather than read, and the count is shown. Two
identical 12 GB ISOs are not a case worth making everyone wait for.

The oldest copy in a group is kept.

## Requirements

Windows 10 or later. Python 3.11+ if you want to run it from source.

Nothing else — no Python, no dependencies, no account, no network access.

## SmartScreen

The executable is not code-signed, so Windows will warn on first run. Click
**More info** → **Run anyway**. There is no certificate behind it, so the warning
cannot be suppressed honestly.

## Known issues

Read [KNOWN_ISSUES.md](https://github.com/stopcinning/FileFlow/blob/main/KNOWN_ISSUES.md)
before filing anything. The short version: Windows only, files over 8 GB are
skipped by duplicate detection, and the journal is never pruned unless you ask.

## Feedback

Issues and discussions are open. If a file ends up somewhere you did not expect,
say so in the issue — that is worth prioritising over a crash.
